**主线**：《蝉鸣止于逢魔时》第一章（开箱即演，不新增内容）

**成片时长**：88–92 秒（含 2 秒黑场收尾）
**录制规格**：横屏 1920×1080（或 2340×1080 超宽），60 fps 采集后 30 fps 交付；
浏览器 1440×900 起录，`node serve.js` 后 Ctrl+F5 冷启动，静音录制、后期配音效。
**录制前必做**：清一次 localStorage（`mumu.saves.v2` / `mumu.autosave.v1` / `mumu.gallery.v1`），
保证开场动画与第一章第一句从零开始；首次进入需点一次遮罩解锁音频，录完再把这一段剪掉。

## 剪辑与呈现红线

1. **不要用页面外的假 UI**。所有画面必须是真实浏览器录屏，包括打字机逐字与选项 hover；
   宁可慢，不要合成假交互。
2. **对话框文字永远可读**：任何一帧都不能有人物立绘压住台词（这是项目验收标准，成片同理）。
3. **不出现浏览器地址栏、书签栏、滚动条**；F11 全屏录制，或裁掉顶部 90 px。
4. **不出现英文报错、favicon 404 之外的控制台痕迹**；录制前确认控制台为空。
5. 字幕只补「数字与机制」（27 场景 / 22 道具 / 19 选择 / 38 选项 / 445 用例 / 272 ms），
   台词一律用页面原字，方便观众对着录屏核对。
6. 左下角保留项目既有免责声明：「剧本由AI生成，如有雷同，纯属巧合」。
7. 竖屏素材只用来说「我们按横屏设计」：手机 390×844 出现「请横屏体验」提示层那 1.5 秒可以留，
   但不要把竖屏当主体验展示。

## 备用素材（若第一章节奏不够快可替换）

- 《青绿长卷》第三章「隐瞒 / 坦诚」→ 紫檀木盒先合后开 → 暗红矿石 → 研钵，道具动效最强。
- 《漩涡与深蓝》第二章画库的**逆向《星月夜》**特写，视觉冲击最大（真实名画镜像）。
- 《月光下的未完奏鸣》第一章「橘子汽水」特写 + 夜晚完美合奏，情绪最亮。
- 四段开场动画连播（蝉鸣 / 青绿 / 月光 / 漩涡，各取标题浮现那 2 秒）适合做 15 秒短版。
