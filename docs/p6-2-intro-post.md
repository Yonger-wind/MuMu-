## 长版

### 暮幕 MuMU：一个打开就能演的互动剧本舞台

**一句话**：它不是"点击继续的文字游戏"，而是一个把分镜、光影、道具、立绘都画在舞台上的
**互动剧本舞台**——你在浏览器里点开，它就开演。

#### 二、它和别的互动剧本有什么不同

1. **舞台是画出来的，不是贴图。** 27 类场景（教室、操场、神社、宫苑、丹青阁、沙龙、书房、庄园、
   画库、旧琴房、钟楼、草坪、陆家嘴、写字楼、清吧、老剧院……）全部 Canvas 2D 分层绘制，
   晨 / 昏 / 夜 / 火夜四种光实时换算，起居室有壁炉火焰与木框线脚，庄园外墙有瓦垄与石砌缝。
2. **分镜会取景。** 远景 / 中景 / 近景 / 特写是引擎概念而不是形容词：单人、双人、三人、过肩、背影
   各有构图规则，人物只站在对话框左右两侧，永不压住文字。
3. **特写里东西能拿起来看。** 22 类道具（旧磁带、耳机、贴纸、信纸、长卷、令牌、紫檀木盒、研钵、
   《星月夜》及其镜像、手抄《悲怆》乐谱、小提琴、钢琴键盘、橘子汽水、素圈戒指……）
   木盒会先合后开，同一段特写里道具不会突然消失。
4. **人物只有剪影，但情绪可读。** 28 张深紫黑半身立绘 + 克制的暖/冷边缘光 + 空气透视 + 接地软阴影，
   没有五官、没有表情贴图，靠姿态、朝向和光说话。
5. **开场动画是独立的。** 四部曲的第一章各有专属 WebGL2 开场（黄昏海面 / 千里江山青绿山脊 /
   深蓝夜空金色五线谱 / 星月夜漩涡），约 6.2 秒浮现大标题，不支持 WebGL2 自动回落 Canvas 2D。
6. **你的选择留得下痕迹。** 逐句回退、自动存档、终幕结算卡（这一幕 / 最后一句台词 / 你的选择 /
   获得卡牌），刷新页面也能一键续演。
7. **能收卡，也能自己做卡。** 角色图鉴 4 张典藏卡开局可用，曲目角色卡按章节通关解锁；
   「自定义卡片」页可以上传本地图片做成同款全息卡（12 项效果可调、最多 5 星、12 张）。
8. **作品能带走。** 内置曲目可导出为 `.mumu` 作品包（ZIP + manifest），别人导入即可播放；
   自己写的 `.txt / .md / .json / .docx / .zip` 也能直接导入，200–30000 字皆可。

#### 三、技术与体验口径

- **零依赖、零构建**：原生 HTML / CSS / ES Modules + Canvas 2D + WebGL2 + Web Audio，
  没有框架、没有打包器、没有后端。
- **本地优先**：作品库、存档、图鉴、自定义卡片全部留在浏览器 localStorage，上公网也不引入账号。
- **首屏实测**（本机 headless Edge、冷缓存、无 gzip）：首屏可交互 **272 ms**，
  **34 个请求 / 643 KB**，首屏图片请求 **0 个**；首页 44.7 FPS、舞台 52.0 FPS，控制台异常 0 条。
- **质量**：**445 个自动化用例**通过；`node tools/lint.js --builtin` 内置 15 章无问题；
  四部曲 15 章逐章、逐分支浏览器回归走通。
- **移动端按横屏设计**：舞台是横向分镜，竖屏打开会提示「请横屏体验」（可以坚持继续，但会提醒你）；
  844×390 与 812×375 的矮视口布局逐面截图验收过。
- **剧本角色形象由 AI 生成，如有雷同，纯属巧合。**

#### 四、为什么做它

因为"互动剧本"这四个字常被做成了"配图翻页"。我们想试试另一条路：
把舞台当作第一公民——分镜怎么取景、光从哪来、道具怎么被拿起来、人物站在哪一侧、
选择怎样在下一幕留下痕迹。它仍然是一个能写、能导、能分享的剧本工具，
但打开它的那一刻，先看到的是一幕戏。
