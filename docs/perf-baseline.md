# 首屏性能基线（P0-5）

**采集方式**：`PORT=5199 node serve.js` + `node tools/perf-baseline.cjs --runs=3 --stage`
**采集日期**：2026-11-24（基线列 = P0-5 立绘/场景图懒加载前；懒加载后列 = 同一台机器、同一 Edge 版本，各自冷缓存导航复跑；每次调用新起 Edge，同一调用的 3 轮共用该进程）
**环境**：headless Edge（本机），1440×900，DPR 1，`Network.setCacheDisabled(true)` 冷加载；本地服务器无 gzip、无缓存头。每项 3 次取中位数。
**指标口径**：首屏可交互 = 导航开始 → `load` 完成 + 字体就绪 + 连续两帧 rAF，由 `Page.addScriptToEvaluateOnNewDocument` 注入的脚本在页面内用 `performance.now()` 写入 `window.__readyAt`（不含 CDP 轮询与往返开销）；体积 = `transferSize` 按类型汇总；请求数 = 子资源 + 1（HTML 文档本身）；FPS = 首页夕阳 / 舞台采样 3 秒；舞台 FPS 在入场遮罩未关闭的舞台页采样（前后同条件，只作同机对比）。

| 指标 | 基线（P0-5 改动前） | 懒加载后 | 变化 |
|---|---|---|---|
| 首屏可交互（ms） | 383 | 247 | −136（−36%） |
| load（ms） | 328 | 140 | −188（−57%） |
| 首屏请求数 | 53 | 21 | −32（−60%） |
| 首屏图片请求数 | 32 | 0 | −32（图片请求全部推迟到交互后） |
| 首屏总字节（KB） | 5806 | 1280 | −4526（−78%） |
| JS 字节（KB） | 1256 | 1259 | +3（+0.2%，懒加载调度代码） |
| 图片字节（KB） | 4529 | 0 | −4529（−100%） |
| 首页 FPS | 47.1 | 47.4 | +0.3（持平） |
| 舞台 FPS | 58.0 | 58.7 | +0.7（持平） |

**结论**：

1. 首屏少 32 个图片请求、约 4.5 MB —— 二十八张立绘改为首页空闲后分批加载，四张场景大图改为首次交互（打开剧本库 / 进入舞台）后加载，首屏只剩 HTML / CSS / JS。
2. 首屏可交互 383 → 247 ms（−36%），load 328 → 140 ms；`load` 与 DCL 同步，说明首屏不再等待任何图片解码。
3. 首页 47.4 FPS、舞台 58.7 FPS，中位数差 < 2%（首页两列合计单轮 42.8–48.7：基线列低至 42.8，懒加载后为 46.4–47.7，属机器噪音）；立绘分批预加载没有引入掉帧，舞台 P95 帧间隔仍是 16.8 ms。首轮 ready 392 ms 含冷启动热身，取的是 3 次中位数。
4. 首次进入舞台后会自然补齐 32 个图片请求（回归实测全部 200），画面与改动前一致；本地/回归环境下场景首次出现时大图已就位；慢网下先走既有程序化降级，大图到达后自动重绘，不需要另做预热点。

**补充数字**：DCL 140 ms · TTFB 7 → 10 ms · CSS 21 KB · 首页 P95 帧间隔 33.4 ms（>20 ms 共 39 → 38 帧，3 次中位数）· 舞台 P95 帧间隔 16.8 ms（>20 ms 共 6 → 4 帧）。
**已知限制**：四张场景大图在本次页面会话内只请求一次（sceneImagesRequested 置真后不再重试）；任一张瞬时失败，本次会话保持程序化降级画面，刷新页面后重新请求。立绘有 5 s / 2 次的有界自动重试，场景图没有（与懒加载前的单次加载行为一致）。
**已知噪音**：唯一控制台/网络异常是 `http 404 /favicon.ico`（浏览器自动请求，`serve.js` 无此文件，与 P0-5 无关，每轮 1 条，报错按 `run N:` 标注轮次）；该请求也计入「首屏请求数」与 `ico 0 KB` 分类。headless Edge + `--disable-gpu` 下的 FPS 只作同机前后对比用。

**如何复跑**：`PORT=5199 node serve.js &`，然后 `node tools/perf-baseline.cjs --runs=3 --stage --out=.tmp-perf/after.json`（上表「懒加载后」列即该文件的中位数）。数字随机器与 Edge 版本变化，对比只认同机同版本 Edge 的多次冷缓存导航中位数（每次调用新起 Edge）：首屏可交互允许 ±5% 波动、FPS 允许 ±10%；采集器会先校验 9334 端口归属（占用即报错退出）、校验导航后页面为 `http:` 且含 `#btn-start`，任一轮异常都不会产出「看似正常」的 0 值。
**不做项**：`scene.js` 按场景拆分/分片未在 P0-5 内执行（改动面大、收益低于图片懒加载），延后到后续性能切片；本表只覆盖首屏与舞台帧率两项。
