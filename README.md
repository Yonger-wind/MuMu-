# 暮幕 MUMU · 互动剧情舞台

> GitHub（私有）：https://github.com/Yonger-wind/mumu

一个零依赖的网页互动剧情游戏：唯美印象派场景 + 半身剪影立绘 + 分支叙事。
纯原生 HTML / CSS / ES Modules + Canvas 2D + Web Audio，无构建步骤、无第三方依赖。

## 运行

```bash
node serve.js
# 打开 http://localhost:5173
```

必须通过 HTTP 访问（ES modules 不支持 file:// 直接打开）。`serve.js` 无缓存头，
改代码后请强制刷新（DevTools 勾选 Disable cache，或 Ctrl+F5）。

单元测试（零依赖，Node 内置测试运行器）：

```bash
node --test          # 运行 tests/*.test.mjs
```

存档写入 `mumu.saves.v2`，旧版本 `mumu.saves.v1` 的存档会在读取时自动迁移补齐；
存档同时携带故事状态（旗标、数值、结局标识、检查点），因此读档可以回到原位继续。

游玩进度另有自动存档（`mumu.autosave.v1`）：每读完一句、每次选项出现都会覆写当前这一程，
本章走到【结束】即清除。刷新页面后首页出现「继续上次」，点一下回到刚才那一句；
它不占用手动存档的 40 条名额。

首页右上角的「角色图鉴」（`mumu.gallery.v1`）收录 4 张开局即得的典藏卡
（星月夜，以及 Aeolian / ᥫᩣo.O / 彼岸洛luo 三位创作者，星级 7/7/6/6）与四部内置曲目的
27 位角色卡。内置剧本每通过一章会按剩余人数/剩余章节分配 2~3 张角色卡（同章重结算不重复发），
发卡结果写入本地存储；角色卡统一为深靛斜纹的立式卡面（4:5.4），半身剪影以 contain 完整留在卡内、
不被卡框裁切，名字落在左下、星点落在右下，身份只在详情里出现；
图鉴内点已解锁卡片进入近黑展示台上的全息检视（持续扫光、倾斜、手机陀螺仪），
未解锁卡片只显示静态剪影与获得提示。图鉴面板底栏固定标注
「剧本角色形象由AI生成，如有雷同，纯属巧合」。

图鉴顶部还有一个「自定义卡片」页（`mumu.customcards.v1` + `mumu.customcards.fx.v1`）：
用「＋ 新增卡片」或「上传图片」（也可把图片直接拖进卡片区）做自己的全息卡，复用图鉴同一套卡面渲染。
每张卡自带「换图」「删除」（删除要连点两次确认），卡面上的名称与身份可以就地改（Enter 保存、Esc 还原），
点星星即可打分。右侧「效果调节」面板只有 12 项——彩虹强度、覆膜强度（默认自动，按图片是否透明底取值）、
高光、倾斜角度、视差、圆角、主题（暗色/亮色）、画幅、箔层花纹（无/斜纹/光栅/星点/蜂窝）、
星星颗数、批量星级、显示星级，面板上写明「只作用于下方的自定义卡片」。
硬限制：自定义卡星级最多 5 星、最多 12 张、图片本地压到最长边 1000px 后只存在浏览器里
（空间不够时卡照样存下、图片降级为无图卡并给中文提示）。内置角色卡与典藏卡的参数是固定的，
面板怎么调都不会影响它们。在自定义页按 Esc 先退回「角色图鉴」页，再按一次才关闭图鉴。

自定义卡片还可以**单独检视**：点卡面本体进入和内置卡同一套近黑展示台的全屏全息检视
（大卡、入场扫光、倾斜与手机陀螺仪），底部有 `‹ 1 / 3 ›` 翻页条可以在自己的卡之间前后翻、
首尾循环（只有一张时不显示）；检视里点星星同样会写回这张卡并同步列表；✕ 或 Esc 退回卡片区。
内置卡与典藏卡的检视不带翻页条，行为不变。

首页可以**下滑**：第一屏是黄昏主视觉，往下滑一屏是「项目介绍」——原来的「玩法与格式」弹窗内容
已合并进这一屏（演什么 / 怎么玩 / 怎么演 / 剧本怎么写 / 存档与音乐 / 图鉴与卡片），弹窗本身删掉了。
主标题下的「项目介绍」按钮和「下滑看项目介绍 ⌄」都平滑滚到那一屏；介绍页底部的「开始体验」回到首页
并打开剧目选择，「回到首页」滚回顶部。只有 `#home` 自己是滚动容器，`html / body` 仍是 `overflow:hidden`，
剧情舞台与 `#ui-layer` 悬浮层都不跟着滚，回到首页时 scrollTop 自动归零。

「开始体验」进入全屏环形剧本选择：四部曲目与用户导入的剧本排在同一条 3D 卡带上，
默认居中《漩涡与深蓝：星月夜的回响》（左邻《月光下的未完奏鸣》、右邻《青绿长卷·千里未归》）；
拖动 / 滚轮 / ← → 浏览，也可点两侧的「〈」「〉」按钮单步切换；居中封面下方会出现裸露的
「开始体验」小白字，点它或按回车进入章节（点封面本身不进入）；真实剧本不超过 10 部时补 7 张「敬请期待」占位卡
（占位卡不占阈值名额），超过 10 部则自动回退为原来的陈列弹窗。曲目卡带关键词
（蝉鸣「青春校园」、青绿「古风」、漩涡「悬疑」、未完奏鸣「言情」），页脚角落标注
「剧本由AI生成，如有雷同，纯属巧合」。用户导入的剧本仍可在卡带里点开章节抽屉更换封面图
（压成 620×830 JPEG 后随剧本一起存进本地）。

进入剧情后，发言人名称下方会显示一行小字身份（如「高三学生 · 旧磁带的主人」），
取自图鉴的曲目角色数据；身份只对内置曲目生效，《蝉鸣》里的小悠真 / 小葵不显示。

对话框右上角有「‹ 回退一句」：点一次只退一屏画面（不会一口气跳回很远），但可以一直点、逐步退回
本章更早的每一句，直到第一句时按钮自动隐藏。停在选项上回退会回到最近的一句台词并收起选项，
停在【结束】页回退会收起结算卡、回到末尾那句；回退后再往前走，会丢弃先前被退掉的那些台词，重新走下去。

舞台右上角常驻两个按钮：「换个剧本」直接在当前画面上打开完整的剧目选择层（不先离开剧情，
误触时点「返回剧情」即可回到原来的那一句）；「选章节」直接打开正在体验这部曲目的章节抽屉，
正在看的曲目会先转到正前方，关闭后回到原来的剧情。从首页或落幕结算卡进入选择层时，
关闭按钮仍是「返回首页」。

从章节列表点进四部内置曲目的**第一章**时，会先播放各自的专属开场动画（《漩涡与深蓝》是
星月夜在深蓝里旋成涡卷，《蝉鸣止于逢魔时》是橙金涡卷天空绕着半升落日、海面泛金，《青绿长卷·
千里未归》是薄荷天下山峦由等高线织成、山脊洒金，《月光下的未完奏鸣》是金与冰蓝的五线谱带
盘成漩涡、金粉星屑漂浮）。笔触逐帧生长，《漩涡》约 7.2 秒、其余三部约 6.2 秒浮现大标题，
标题下方多一行「点击任意处开始剧本」；点任意处、回车或空格开演，右上角小号「跳过动画」或
Esc 可随时跳过。动画只在每一部曲的第一章触发，第二章起、「继续上次」与读档都不会重播；
自定义剧本没有开场动画。WebGL2 不可用时自动退回 Canvas2D 绘制，系统开启「减少动态」时
缩短到片头即可开演。

曲目**终章**走到【结束】时，落幕文案下方会出现一张结算卡：这一幕（时间 · 场景）、
最后一句台词、这一程做过的选择、本轮获得的角色卡；非终章不显示，保持「继续下一章」的节奏。
结算卡只存在内存里，不进存档，重开或离开舞台即清除。

## 内容校验

剧本写完可以用零依赖的校验器自检（不参与游戏运行）：

```bash
node tools/lint.js 剧本.txt        # 校验单个 .txt / .md 剧本
node tools/lint.js --builtin      # 校验内置 15 章
node tools/lint.js --builtin --json   # 机器可读输出
node tools/lint.js 剧本.txt --strict  # 把警告也算失败
```

每条问题都带**行号 + 规则码 + 原因 + 修法提示**；退出码 0 = 通过，1 = 有错误（`--strict` 时 warning 也算），2 = 用法错误。
规则码表见 [docs/mumu-lint-rules.md](docs/mumu-lint-rules.md)。

## 性能基线

首屏与舞台的性能可以用同一套零依赖采集器复跑（先 `PORT=5199 node serve.js`）：

```bash
node tools/perf-baseline.cjs --runs=3 --stage --out=.tmp-perf/after.json
```

口径（首屏可交互 = `load` + 字体就绪 + 连续两帧 rAF、体积按 `transferSize` 汇总、FPS 采样 3 秒）、
改动前后的对比数字与已知噪音见 [docs/perf-baseline.md](docs/perf-baseline.md)；
只有同一台机器、同一 Edge 版本的两次结果才有可比性。

当前数字（2026-11-26 复测，3 次中位数）：首屏可交互 **272 ms**、首屏 **34 请求 / 643 KB**
（CSS 107 KB + JS 536 KB，图片请求 0 个）、首页 44.7 FPS / 舞台 52.0 FPS、控制台与网络异常 0 条。
`scene.js` 与 `prop.js`（合计 951 KB）通过 `scripts/lazy-scene.js` 的同接口懒加载代理移出首屏导入图，
首次需要绘制场景时才动态 import；加载失败只提示一次中文 toast，不产生未处理的 rejection。

## 扩展接口

第三方卡牌检视、UI 模块与素材的接入契约见 [docs/extension-contracts.md](docs/extension-contracts.md)：
卡牌 = 新增 `scripts/cards/<cardKey>.js` + 在 `assets/cards/manifest.json` 注册；
UI = 新增模块 + `mountTo('<slot>', node)`；视觉只使用 `styles/tokens.css` 的 `--mumu-*` 令牌。

## 部署

最终网站由 **Qoder 部署到 Qoder Sites**（唯一部署目标）。
本仓库保持零依赖、零构建的纯静态形态，可直接被 Qoder Sites 托管
（`index.html` + `scripts/` + `styles/` + `assets/`）；作品库与存档仍留在访问者浏览器本地，
不因上公网而引入账号或服务端依赖。部署约束见
`docs/superpowers/specs/2026-11-23-mumu-local-creation-platform-roadmap.md` §7。

**线上地址：待部署后回填**（P6-2 的部署动作单独执行，是 P0-6 文档收尾唯一未完成的一项）。
部署前必须过 roadmap §8 回归矩阵与 `docs/perf-baseline.md` 的首屏基线；移动端按**横屏**体验设计，
竖屏打开时会出现「请横屏体验」提示层（可「仍以竖屏继续」），矮视口（≤460px 高）另有专门的布局重排。

纯环境描写的段落不写台词，画面只展示场景。夜晚的操场与神社（室外）会自动出现一轮柔和满月，
公司、教室等室内场景不画月亮（宫苑/丹青阁/庄园/起居室等室内夜戏也不画）。人物站位固定：先出场者在左、
下一批在右，交替出现；立绘只出现在对话框两侧，不遮挡文字。特写道具按当前台词关键词自动选择
（长卷/画卷/卷尾→长卷，令牌/玄铁→令牌，紫檀木盒/木盒→木盒，研钵/颜料/矿物→颜料研钵，
磁带/录音→磁带，耳机，信/信纸→信纸，文件/表格→纸张，照片/相片→旧照片，星月夜/星空/画布→星月夜，
放大镜/透镜→放大镜，档案/卷宗→档案袋，账本/黑皮→黑皮账册，星图/紫外→星图，手机/短信→手机，
碎片/残片→画布碎片，咖啡→咖啡，手抄/乐谱→手抄乐谱（可直接叠印真实《悲怆》乐谱图），
小提琴/琴弓/松香→小提琴，钢琴/琴键→钢琴键盘，汽水/易拉罐→橘子汽水，戒指/素圈→素圈戒指），
同一段特写内道具会延续到下一句，不会因为旁白没提到物件而突然消失。

括号情绪允许较长描写（如"看着天色，眉头微蹙"），仅当名字已在角色表中声明时生效，
不会把普通叙述误判成台词；未声明名字仍按 6 字以内判定，旧剧本行为不变。

选择可以留下后果：选项末尾写 `@asked_tape`，选中即把旗标置真；后续行首写
`?? asked_tape | …` 才播放，写 `?? !asked_tape | …` 则在未发生时播放。条件只允许用在
台词/旁白与场景、镜头、姿态/动作、视角、出场、清场这些舞台指示上，不能用在选项、跳转、
标签、角色表与【结束】上。「继续下一章」会把本章旗标带进同曲目的下一章；直接从章节列表
进入或「重新开始」不会继承。

## 作品包 .mumu

作品包是把一部作品（单章或整本）整体带走的文件：一个 `.mumu` 就是标准 ZIP 容器，
里面是 `manifest.json` + 剧本文本 + 可选封面。导出与导入全部在浏览器内完成，不上传服务器。

- **导出**：内置曲目卡有「导出整本」（整本包）；独立卡有「导出 .mumu」、章节列表的每一行有
  「导出」（都是单章包）。下载文件名：整本为 `曲目标题.mumu`，单章为
  `曲目标题 · 章节标识.mumu`；包内 `title` 保持作品原标题不变。
- **导入**：首页「导入」支持 `.mumu`（拖入或选择文件）。坏包会给出中文报错并且**不写入任何数据**；
  与内置曲目同名时导入为新卡片，不覆盖内置剧本。
- **包内结构**：`manifest.json`（包清单）+ 剧本文本（单章 `script.txt` / 整本 `chapters/01.txt`…）
  + 可选封面 `assets/cover.<png|jpg|webp>`（按封面实际格式落扩展名；导出时另附模板生成的
  `README.md`）。封面支持 PNG / JPEG / WebP。
- **限额**：整包 32MB、单个资源 4MB、解压后 64MB、单章文本 5MB、单章字数 30000 字
  （导入与导出都卡这道字数上限，保证导出的包一定能被自己导回来）；封面入库前缩到最长边
  640px 的 JPEG。
- **库内管理**：非内置的独立卡有「导出 .mumu」与「移除」；曲目卡有「导出整本」，
  非内置曲目另有「移除整本」与「已导入」徽标。移除只在浏览器本地生效。

字段表、许可证与二创规则、DSL 速查、常见报错与处理见 **[docs/mumu-package-spec.md](docs/mumu-package-spec.md)**。

## 设计原则（修改时必须遵守）

1. 半身剪影立绘：深紫黑剪影、无五官、服装/发型只留轮廓；只出现在对话框左/右两侧，
   比例克制（远景 0.36、中景 0.42、近景 0.56 屏高），底部柔和渐隐融入画面。
2. 外观不推断：只使用 `scriptId:cid` 稳定分配 + 剧本明写的模型/性别线索，禁止按姓名推断。
3. 场景融合：按场景调色板出暖橙/冷蓝紫边缘光（两层弱光晕，禁止霓虹描边）、空气透视、
   脚下软阴影，人物要"站在光里"而不是贴上去。立绘使用素材自带边缘，不额外描边。
4. 不破坏业务：剧情解析、人物识别、对话播放、分支、存档、导入、分镜必须保持可用；
   旧存档缺新字段时一律给默认值。
5. 零依赖、无构建步骤；布局与整体 UI 风格保持现状，不做整体重构。
