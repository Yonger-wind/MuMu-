# 暮幕 MUMU · 互动剧情舞台

一个零依赖的网页互动剧情游戏：唯美印象派场景 + 极简氛围剪影人物 + 分支叙事。
纯原生 HTML / CSS / ES Modules + Canvas 2D + Web Audio，无构建步骤、无第三方依赖。

## 运行

```bash
node serve.js
# 打开 http://localhost:5173
```

必须通过 HTTP 访问（ES modules 不支持 file:// 直接打开）。`serve.js` 无缓存头，
改代码后请强制刷新（DevTools 勾选 Disable cache，或 Ctrl+F5）。

## 目录结构

```
index.html          首页（动态夕阳 + 塔）与剧情舞台两个屏幕
serve.js            零依赖本地静态服务器（node serve.js）
styles/main.css     全部样式（保留现有视觉，勿整体重构）
scripts/
  main.js           主控：屏幕切换、按钮装配、音频/渲染器/引擎接线
  sunset.js         首页 Canvas 动态夕阳主视觉
  scene.js          剧情舞台渲染器：四类场景底图、晨昏夜光影、浮尘、镜头推拉、
                    人物编排（远景/中景/近景/特写、双人、过肩、背影）
  silhouette.js     人物剪影系统（核心视觉）：稳定体型生成 bodySpec、7 姿态 POSES、
                    6 动作 ACTIONS、drawSilhouette 剪影绘制、drawHandDetail 手部+道具特写
  engine.js         剧情引擎：节点推进、打字机、选项、场景/姿态/视角状态、快照存档
  parser.js         剧本解析（.txt/.md/.json/.docx/.zip）：台词、分支、舞台指示标签
  character-manager.js  角色 cid 分配与剪影体型装饰（仅剧本明写的线索）
  builtin.js        内置剧本《雨后的操场》（演示全部镜头与舞台指示）
  storage.js        localStorage：自定义剧本 mumu.scripts.v1 / 存档 mumu.saves.v1
  modals.js         剧本库 / 存档 / 导入 / 玩法说明弹窗
  audio.js          Web Audio 程序化轻音乐（可静音、切曲）
```

## 剧本格式速查

```
标题：xxx
简介：xxx
角色：
林夏 | 女 | 长发 | 红
陈默 | 男 | 短发 | 蓝

【场景：操场 | 黄昏 | 远景】     场景：公司/教室/操场/古建筑 · 时间：黄昏/白天/夜晚 · 镜头：远景/中景/近景/特写
【镜头：中景】                   中途改景别（特写 = 手部 + 台词关键词道具）
【姿态：难过】 【姿态：林夏|难过】 身体语言，可指定角色
【动作：坐下】                   站立/行走/坐下/转身/低头/抬头
【视角：过肩】                   常规/过肩/背影
林夏（开心）：台词               行内情绪，只影响这一句
名字：台词 / 旁白：…            普通对白与旁白
> 选项 -> 标签                  分支；[标签] 落点；-> 标签 跳转；【结束】收尾
```

特写道具按当前台词关键词自动选择：水/瓶→水瓶，信/票/纸→纸张，手机/电话、杯/茶/咖啡、铃、琴。

## 设计原则（修改时必须遵守）

1. 极简氛围剪影：深紫黑整体剪影、无五官、服装/发型只留最简轮廓；玩家想象脸，情绪靠姿态与镜头。
2. 外观不推断：只使用 `scriptId:cid` 稳定生成 + 剧本里明确写下的性别/发型线索，禁止按姓名推断。
3. 场景融合：按 `PALETTES.warm` 与 `LIGHT_POS` 出暖橙/冷蓝紫边缘光（两层弱光晕，禁止霓虹描边）、
   路径内空气透视、脚下软阴影，人物要"站在光里"而不是贴上去。
4. 不破坏业务：剧情解析、人物识别、对话播放、分支、存档、导入、分镜必须保持可用。
5. 零依赖、无构建步骤；布局与整体 UI 风格保持现状，不做整体重构。
